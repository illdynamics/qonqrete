# Swift Small: Duration Formatter

## Goal
Create a Swift CLI that formats durations into human-readable text.

## Requirements
- Accept seconds as input and output days, hours, minutes, and seconds.
- Support compact and verbose modes.
- Handle negative, zero, and very large values.
- Include Swift Package Manager tests.

## Acceptance Criteria
- `swift test` passes.
- Output is deterministic.
- Invalid input exits non-zero with helpful usage.

## What This Test Measures
- Can QonQrete produce a complete, runnable solution rather than only a sketch?
- Can it handle edge cases and write usable tests?
- Can it explain setup and usage clearly without hiding assumptions?
