# C++ Small: Expression Calculator

## Goal
Write a modern C++ command-line calculator.

## Requirements
- Parse +, -, *, /, parentheses, and unary minus.
- Provide useful syntax errors with positions.
- Use tests for precedence, parentheses, division by zero, and malformed input.
- Include CMake setup.

## Acceptance Criteria
- `cmake --build` and tests pass.
- No undefined behavior on invalid expressions.
- Parser code is separated from CLI code.

## Constraints
- Use C++17 or newer.

## What This Test Measures
- Can QonQrete produce a complete, runnable solution rather than only a sketch?
- Can it handle edge cases and write usable tests?
- Can it explain setup and usage clearly without hiding assumptions?
