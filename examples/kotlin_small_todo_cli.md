# Kotlin Small: Todo CLI

## Goal
Build a Kotlin command-line todo list.

## Requirements
- Commands: add, list, done, delete, clear-done.
- Persist todos in a local JSON or text file.
- Support priority and due date fields.
- Include unit tests for storage and command parsing.

## Acceptance Criteria
- Gradle build passes.
- Re-running commands preserves data.
- Invalid dates and unknown commands are handled cleanly.

## What This Test Measures
- Can QonQrete produce a complete, runnable solution rather than only a sketch?
- Can it handle edge cases and write usable tests?
- Can it explain setup and usage clearly without hiding assumptions?
