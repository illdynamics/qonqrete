# Kotlin Big: Habit Tracker API

## Goal
Build a Kotlin REST API for tracking habits.

## Requirements
- Implement habits, daily completions, streak calculation, and weekly summary.
- Persist to SQLite/Postgres or an embedded database.
- Add input validation and consistent error responses.
- Include integration tests for creating habits and calculating streaks.
- Provide Docker or local run instructions.

## Acceptance Criteria
- Project starts and tests run from a clean checkout.
- Streak calculations handle missed days and timezone boundaries.
- API examples are documented.

## Stretch Goals
- Add a small CLI client or OpenAPI spec.

## What This Test Measures
- Can QonQrete produce a complete, runnable solution rather than only a sketch?
- Can it handle edge cases and write usable tests?
- Can it explain setup and usage clearly without hiding assumptions?
