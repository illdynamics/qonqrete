# qontract.d/ — Project Constitution

This directory holds the **QONTRACT** (project constitution) generated by InstruQtor during cycle 1.

## Files

- `qontract.md` — Human-readable contract (included in AI prompts)
- `qontract.json` — Machine-parseable contract (used by QontractGuard)

## Rules

1. Generated ONCE in cycle 1 by InstruQtor
2. MANDATORY for all subsequent cycles (fail-fast enforcement)
3. Used by: ConstruQtor (prompt context), InspeQtor (guard + AI context), QontractGuard (enforcement)
4. Never regenerated — stable across cycles
